# 🤖 HealthCare Chatbot with Appointment Booking 🏥

Welcome to the **HealthCare Chatbot** repository! This chatbot is designed to assist users with medical queries, provide detailed information via links, and allow users to book appointments seamlessly. 💬🗓️

---

## ✨ Features

✅ **Chatbot Interaction**: Users can ask medical-related questions and receive informative text responses. The chatbot also provides useful links for in-depth details on specific topics. 🔗💡  
✅ **Appointment Booking**: Users can book appointments through the chatbot. The system only allows bookings within a 15-day window from the current date to ensure timely scheduling. 📅✅  
✅ **Responsive Design**: The interface is optimized for **desktop & mobile** use, providing a seamless experience across all devices. 📱💻  


---
## 🛠️ Technologies Used

🔹 **Frontend**: HTML, CSS, JavaScript 🎨🖥️  
🔹 **Backend**: JavaScript, Python 💻🐍  
🔹 **Appointment Logic**: JavaScript-based backend validation to enforce the 15-day appointment restriction 📅⚙️  

---

## 🏥 Appointment Booking Logic

To ensure **valid & timely bookings**, the system restricts users to selecting dates **only within 15 days** from the current date. If a user attempts to pick a date beyond this range, an **error message** will appear. ❌⚠️  

---

## 🔗 Chatbot Link Responses

For **complex queries**, the chatbot provides users with **clickable links** to **reliable health resources**. Users can access information about **diseases, symptoms, treatments, and more** with just one click! 🩺📖🔍  

---

## 🚀 Usage

🗨️ **Ask Questions**: Type your medical queries into the chatbot and receive instant responses.  
📅 **Book Appointments**: Choose a valid date from the appointment booking section.  
🔗 **Access Links**: Click on the provided links for in-depth medical articles and resources.
